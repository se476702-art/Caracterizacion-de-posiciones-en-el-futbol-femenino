# Caracterizaci-n-de-posiciones-en-el-f-tbol-femenino.
El análisis de las posiciones en el fútbol femenil es de gran relevancia para comprender el rendimiento de las jugadoras dentro del campo, se emplearon métodos como diferencia de medias, diagramas de caja (boxplots) y modelos de clasificación basados en inteligencia artificial.
