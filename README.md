# Caracterización de posiciones en el fútbol femenino.
Caracterización de posiciones en el fútbol femenino usando análisis estadístico y modelos predictivos

Proyecto desarrollado por Adriana Segovia Rivera
Mayo 2026

# Resumen

El análisis de las posiciones en el fútbol femenino es fundamental para comprender el rendimiento y las características de las jugadoras dentro del campo.

En este proyecto se estudia una base de datos de la National Women’s Soccer League (NWSL) mediante la aplicación de técnicas de análisis estadístico y modelos predictivos basados en inteligencia artificial.

Se implementaron métodos como:

- Diferencia de medias
- Diagramas de caja (boxplots)
- Análisis exploratorio de datos
- Modelos de clasificación

El objetivo principal es identificar diferencias significativas entre las posiciones de juego y detectar patrones de desempeño específicos en las jugadoras.

Los resultados obtenidos permiten contribuir a una mejor evaluación del rendimiento deportivo y al entendimiento de las características asociadas a cada posición dentro del fútbol femenino.

# Metodología
- Limpieza y preparación de datos.
- Análisis exploratorio de variables.
- Visualización estadística de métricas por posición.
- Aplicación de pruebas estadísticas.
- Entrenamiento y evaluación de modelos predictivos.

# Resultados

El análisis mostró diferencias relevantes entre posiciones en variables relacionadas con desempeño físico, ofensivo y defensivo.

Los modelos predictivos lograron identificar patrones útiles para clasificar jugadoras según su posición dentro del campo.
